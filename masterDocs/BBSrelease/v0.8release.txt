[b][size=6]TSRE GenX v0.8 running release work list[/size][/b]
[i]Updated 2026-07-30[/i]
[b][size=5]TERRAIN AND WATER[/size][/b]

[list]
[*][b]DONE[/b] - The F2 Terrain Editor now has a clearer painting workflow with improved labels, UI-scaled controls, validated numeric fields, and the Conform TDB/RDB database brush. It includes paired Main/Snow TERRTEX previews, recent and active swatches, validated ACE/DDS/common-image loading, seasonal mirroring, clearer tool groups, and a pinnable Track Bias helper.
[*][b]DONE[/b] - Added the Waterbed Offset brush for rivers with sloping tile-water planes. It applies a strictly negative offset from the locally interpolated water level while preserving normal brush size, feathering, and Undo. Invalid samples and non-water patches are skipped safely. Height-brush processing was also streamlined to remove redundant terrain lookups and Undo passes.
[*][b]DONE[/b] - Automatic Water and Water Helper now share one persistent, terrain-snapped Water Ruler. It supports continuous placement, saved-ruler recovery, adjustable height and search distance, bounded shoreline scanning, seamless joins, Undo Last, status guidance, and completion sound without loading the full route. One latched toggle starts or removes the ruler, while Process Water Tiles ends placement and leaves the result visible.
[/list]

[b][size=5]ROUTE MANAGEMENT AND DATA SAFETY[/size][/b]

[list]
[*][b]DONE[/b] - The shared Hacks popup is available under • Advanced in Track, Static Object, and Terrain Patch properties. Its launch buttons share the same latched orange state, and track repairs remain disabled without a selected live track. Route Cleanup includes Remove All Interactives, Reset All TERRTEX, Water Tiles Off, and Delete Instances for static, gantry, and collision objects. Delete Instances loads every world tile and removes all matching type/filename instances as one Undo operation. The terrain cleanup tools use atomic tile replacement, separate read/save failure reporting, and safe TERRTEX deletion only after a tile saves successfully. F2 Terrain Utilities is now the focused Track Bias helper.
[*][b]DONE[/b] - Route tools now include Open Route Folder for immediate access to the active route and Create Route Health Report for diagnostic review. The report scans every route world file with AutoFix disabled, records load failures and missing assets, distinguishes valid and duplicate world/sound UIDs, checks TrackShape and SectionIdx definitions, handles the optional route skydome correctly, atomically writes one report in the route folder, and opens it in a standard Copy All review window.
[*][b]DONE[/b] - Route database saving is coordinated and crash-safe across TDB/TIT/TSECTION, RDB/RIT, and modified TRK files. Same-folder atomic replacement, rolling per-route backups, rollback, interrupted-save recovery, truthful status reporting, and visible error feedback prevent a partial save from silently leaving mismatched route databases.
[*][b]DONE[/b] - Fixed a repeatable Route Editor crash when reopening a route in the same process. Traffic IDs no longer contaminate the activity list, traffic-file deduplication is case-insensitive without altering filesystem paths, and invalid activity entries are skipped safely instead of being dereferenced.
[*][b]DONE[/b] - Returning from Route Edit to Main Load now clears route-owned markers, selectors, Undo history, object selection, group/copy state, and Water Helper state. A newly selected route correctly rebuilds markers, Object Selection categories, consists, services, traffic, car spawners, and OR weather transitions.
[/list]

[b][size=5]SETTINGS[/size][/b]

[list]
[*][b]DONE[/b] - Settings are stored exclusively per user in AppData settings.json, with atomic saving, timestamped backups, damaged-file recovery, reset-to-default support, and no runtime dependency on legacy settings.txt. F12 View Markers now loads at startup, so enabling marker-file display also checks View > Markers and displays the route marker file without another manual step.
[*][b]DONE[/b] - AppData housekeeping now keeps only the five newest timestamped settings backups and three newest damaged-settings diagnostics. Route-specific AppData folders are created only when route state is actually written; obsolete empty folders are removed at startup. Crash-safe route database generations remain independently capped at five per route.
[/list]

[b][size=5]DYNAMIC TRACK[/size][/b]

[list]
[*][b]DONE[/b] - Dynamic Track, Classic Flex, and NextGen Auto-Flex now share dependable procedural/fallback materials, a track-following selection outline, a continuous world-space TrackDB guide, normal percent-grade and section information, and a direction-neutral transactional connection solver. The visible mesh and TrackDB vectors are generated from the same endpoint plane, tangent frames, grade, and internal curve-to-straight transitions. Candidates that backtrack, form unintended U-turns, miss either connection, or fail endpoint, tangent, or internal-seam tolerances are rejected without damaging the existing object. Level, graded, and grade-direction-reversed connections were verified with smooth train operation in both directions.
[/list]

[b][size=5]ACTIVITY PATH EDITOR[/size][/b]

[list]
[*][b]DONE[/b] - The F4 Activity Path Editor now provides complete New, Edit, and Clone sessions with cancellation rollback, Undo/Redo, live switch recalculation, reverse and wait points, advanced shunting operations, passing sidings, natural-end routing, stable metadata, stronger PAT validation, atomic saving, and clearer map presentation. The Path Meta Data popup follows the shared GenX editor-dialog style with a dimmed application caption, single orange title, scaled form, and role-accented OK/Cancel controls.
[*][b]DONE[/b] - Stale, disconnected, open-ended, or partly unreadable PAT files can be repaired without terminating the editor. Invalid TrackDB and platform references are skipped with warnings, surviving endpoints remain editable, and unreadable passing branches can be omitted from the draft without changing the original file until Save Path.
[*][b]DONE[/b] - F4 switch throws now provide truthful feedback. Successful main or passing-path recalculations use the established track-placement click; rejected throws restore the previous draft and use the error buzzer. Trailing-point no-op throws are recognized as rejected self-alignment rather than being reported as false successes.
[/list]

[b][size=5]SEARCH, PROPERTIES, AND MAP IMAGERY[/size][/b]

[list]
[*][b]DONE[/b] - Category Search now provides ALL, Tracks, Roads, and Other filters, search-within-category behavior, cleaner Scale Rail grouping, Reset, and a bounded Recent Items list.
[*][b]DONE[/b] - Pasting an object now counts as a placement and adds that object to Recent Items.
[*][b]DONE[/b] - Object Properties panels are being revised for clearer grouping, consistent labels, useful read-only data, common control behavior, and simpler workflows. Selected terrain properties already omit the unused Shader launcher while retaining Shader ID information.
[*][b]DONE[/b] - F3 now uses one GenX provider workflow with keyless OSM Vector plus separately preserved Google, Mapbox, and Custom settings, adjustable map resolution, and live provider changes without a duplicate F12 Map tab.
[/list]

[b][size=5]APPLICATION STARTUP AND WINDOWS[/size][/b]

[list]
[*][b]DONE[/b] - Main Load now appears before the Route Editor and its OpenGL/tool windows are constructed. Load and Restore retain editor reuse without the former artifacts. Delayed PropertiesRuler initialization removes transient standalone field artifacts.
[*][b]DONE[/b] - First-run and Reset settings use a portable baseline: capped frame rate, 2 km object range, 4096-pixel map imagery, neutral UI scale, bounded logs, no machine-specific paths, and conservative cleanup/rebuild options. Main Load is the single startup path, and the Route Editor opens with Properties, Tools, and Control Panel in their intended layout.
[*][b]DONE[/b] - Utility windows now share compact Pin controls, helper framing, UI-scale-aware sizing, position persistence, snapping, mutually exclusive helper visibility, consistent interaction sounds, clearer movement states, and reliable shutdown even when hide-on-close helpers remain open. The Control Panel is shown only after the Route Editor is visible, preventing its pinned tool window from appearing during startup.
[*][b]DONE[/b] - The Route Editor Compass is consolidated into one compact native 8:1 heading tape at half its former display size. It uses a wider, shorter gray presentation with readable direction letters and ticks, two-color cardinal accents, one seamless North marker, no unreadable degree numbers, correct aspect ratio, safe viewport-edge spacing, and atomically persistent View-menu visibility.
[/list]

[b][size=5]CONSIST EDITOR[/size][/b]

[list]
[*][b]DONE[/b] - Consist Editor is available through Main Load in an isolated child process using the selected MSTS/ORTS root and returns when CE exits. Process isolation prevents CE OpenGL and static caches from changing Route Editor lighting or distant-terrain textures. Retired standalone command-line, startup-setting, IDE-preset, and batch-file launch paths were removed from active projects and builds. CE opens maximized with the official GenX caption, orange CONSIST EDITOR title, a selectable root-path subtitle, restrained role-colored launcher actions, and a Route list that excludes Windows shortcuts.
[*][b]DONE[/b] - Rolling-stock compatibility and presentation are more resilient. Normalized .inc paths are resolved through ordered ORTS and MSTS candidates while preserving valid parent-directory paths, and shared .inc definition fragments remain out of stock lists while normal include parsing continues. Preview overlays use one restrained caption size with ellipsis for long names and a compact type/unit marker. Genuinely unresolved stock receives a selectable, scalable, non-mirroring MISSING card with clear selection, Delete/context-menu removal, and right-click Swap Missing with Selected Stock that preserves the chosen replacement.
[*][b]DONE[/b] - Consist Editor presentation and settings now match the rest of GenX. Consist and Shape preview background colors persist independently per user. Popups use dimmed application captions, compact spacing, role-accented controls, concise orange titles with subtitles only for distinct sections, and red warning titles with yellow warning triangles and safe defaults for destructive or unsaved-change decisions.
[*][b]DONE[/b] - Consist Editor production cleanup now releases consist source files and inserted include buffers automatically, removes dead CE and UnsavedDialog declarations, and preserves both CameraFree movement overload sets. Focused static checks and the incremental Release x64 build completed successfully.
[/list]

[b][size=5]SHARED INTERFACE AND DIALOGS[/size][/b]

Reset now clears map credentials/provider state to true 4096-pixel defaults, stale F12 map instructions point to F3, and unused helpers, state, and duplicate includes were removed.

Checked buttons use muted orange, cyan status buttons use palette blue, active controls retain readable charcoal text, non-destructive warning titles use muted yellow, and Water Helper notifications use a cleaner charcoal-and-yellow card. Existing control geometry, accent placement, interaction behavior, destructive red warning treatment, and dim orange TITLE/SUBTITLE styling remain unchanged.
