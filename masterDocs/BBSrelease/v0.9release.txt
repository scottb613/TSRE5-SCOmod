[b][size=6]TSRE GenX v0.9 running release work list[/size][/b]
[i]Updated 2026-07-31[/i]
[b][size=5]APPLICATION PLATFORM AND COMPATIBILITY[/size][/b]

[list]
[*][b]DONE[/b] - v0.9 is a major under-the-hood modernization of TSRE GenX. The complete application has moved from the aging Qt 5/qmake environment to Qt 6.11, CMake, a current 64-bit MinGW compiler, and updated supporting libraries. This removes dependence on obsolete development software, improves compatibility with current Windows systems, and gives future GenX work a maintainable foundation.
[*][b]DONE[/b] - The modern build and deployment system produces one consistent application package with its required runtime components. This makes releases easier to maintain and gives later graphics, texture, performance, and interface improvements a dependable base without repeatedly working around retired Qt 5 technology.
[*][b]DONE[/b] - The Route Editor, Consist Editor, Shape Viewer, Activity Path Editor, terrain tools, route-saving safeguards, settings, and MSTS/Open Rails file compatibility from v0.8 have been carried forward onto the new platform.
[*][b]DONE[/b] - v0.9 is a native 64-bit application for Windows 10 version 1809 or later and Windows 11. Retiring Windows 7 support allows GenX to use current Qt and compiler improvements instead of being restricted by obsolete operating-system requirements.
[/list]

[b][size=5]WINDOWS AND INTERFACE[/size][/b]

[list]
[*][b]DONE[/b] - Application captions and editor windows now use stable modern Windows behavior. Popup placement remains tied to the active screen, and Object Selection dropdowns stay correctly anchored to their controls.
[*][b]DONE[/b] - Closing the Route Editor or returning to Main Load now dismisses every Route Editor helper and popup. Pinned helpers retain their saved positions for the next session but can no longer remain visible after the editor closes.
[*][b]DONE[/b] - Pressing Load without selecting a route now gives the distinct GenX error buzz instead of the normal button sound, making the rejected action immediately clear.
[*][b]DONE[/b] - Terrain Brush Settings fields now size correctly for their contents and UI scale, preventing clipped Size, Intensity, and Max Radius values.
[*][b]DONE[/b] - Water Helper's Above bed up/down arrows now adjust the water height in 0.25-meter increments.
[/list]

[b][size=5]ROUTE EDITOR AND ACTIVITY PATH EDITOR[/size][/b]

[list]
[*][b]DONE[/b] - Camera Terrain Lock now also protects against direct vertical movement through the terrain. Free-camera mode continues to allow unrestricted movement when Terrain Lock is disabled.
[*][b]DONE[/b] - Restored the complete GenX interface sound set. Activity Path Editor point placement now uses the normal placement sound, while accepted and rejected switch actions retain their distinct feedback.
[*][b]DONE[/b] - Corrected Activity AI crossing horn-pattern handling so valid horn instructions are recognized reliably.
[/list]

[b][size=5]CONSIST EDITOR AND TEXTURES[/size][/b]

[list]
[*][b]DONE[/b] - Restored DDS rolling-stock textures throughout the Consist Editor. DXT1, DXT3, DXT5, and common 24/32-bit DDS artwork now appears in both the selected-stock preview and full consist viewport instead of leaving models blank.
[*][b]DONE[/b] - Invalid or unreadable common image textures are now rejected cleanly rather than being treated as loaded zero-size images.
[/list]
